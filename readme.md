📖 About
Portfolio 3D is an interactive 3D web experience built to showcase creative projects and design portfolio in an engaging and immersive way. It leverages WebGL and GLSL shaders to create smooth animations and stunning visual effects that captivate visitors.

---

✨ Features
• ✅ Interactive 3D graphics with WebGL
• ✅ Custom GLSL shaders for visual effects
• ✅ Smooth animations and transitions
• ✅ Responsive design
• ✅ Fast development with Parcel bundler
• 🔜 Upcoming: Mobile optimization
• 🔜 Upcoming: More interactive elements

---

🛠️ Tech Stack
• **JavaScript** (90.3%) - Core application logic
• **GLSL** (4.3%) - Custom shader effects
• **HTML5** (2.7%) - Markup structure
• **CSS3** (1.7%) - Styling
• **Parcel** - Module bundler and dev server
• **WebGL** - 3D graphics rendering

🚀 Getting Started

Prerequisites

```bash
node >= 18.x
npm >= 9.x
```

Installation

```bash
# 1. Clone the repo
git clone https://github.com/sohamchavan07/portfolio3d.git
cd portfolio3d

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

Open http://localhost:1234 in your browser.

---

💡 Usage

```bash
# Start development server
npm run dev

# Build for production
npm run build

# The build output will be in the dist/ directory
```
